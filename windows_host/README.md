# Windows Host

This directory contains the Windows-host side of the portable Hyper-V sandbox.

## Architecture

The upgraded host architecture has two explicit modes:

1. `analysis-base`
   Immutable automation baseline. Every task restores this snapshot before boot and restores it again after shutdown.
2. `maintenance-base`
   Manual login baseline. Use this mode only when you need to update guest tools, Sysmon config, Windows settings, or the guest runtime.

The host must never keep task media attached while refreshing or using baseline snapshots.

## Layout

1. [`powershell/`](/mnt/d/project/ransomware/method12/windows_host/powershell)
   Hyper-V setup, execution, snapshot, and inspection scripts.
2. [`logs/`](/mnt/d/project/ransomware/method12/windows_host/logs)
   Host-side execution logs generated by those scripts.

## Main Host Scripts

1. [`01_prepare_host.ps1`](/mnt/d/project/ransomware/method12/windows_host/powershell/01_prepare_host.ps1)
   Creates the project-local asset directories and verifies Hyper-V access.
2. [`02_new_analysis_vm.ps1`](/mnt/d/project/ransomware/method12/windows_host/powershell/02_new_analysis_vm.ps1)
   Creates the analysis VM. Default generation is now `Gen1`, which matches the working boot path in this project.
3. [`06_install_guest_runtime.ps1`](/mnt/d/project/ransomware/method12/windows_host/powershell/06_install_guest_runtime.ps1)
   Pushes the current guest runtime into a running VM through PowerShell Direct.
4. [`07_refresh_snapshots.ps1`](/mnt/d/project/ransomware/method12/windows_host/powershell/07_refresh_snapshots.ps1)
   Rebuilds the dual-baseline snapshot layout after clearing task disks, DVD media, and automatic checkpoints.
5. [`08_start_maintenance.ps1`](/mnt/d/project/ransomware/method12/windows_host/powershell/08_start_maintenance.ps1)
   Restores `maintenance-base` and boots the VM for manual work.
6. [`09_show_sandbox_state.ps1`](/mnt/d/project/ransomware/method12/windows_host/powershell/09_show_sandbox_state.ps1)
   Prints the current Hyper-V state so you can see whether the sandbox is safe for automated runs.

## Baseline Rules

1. `analysis-base` is not for login, patching, or debugging.
2. Any guest-side change must start from `maintenance-base`.
3. After maintenance is finished, shut the VM down cleanly and rebuild snapshots again.
4. If `09_show_sandbox_state.ps1` reports unexpected snapshots, attached task disks, or DVD media, fix that before the next automated run.
